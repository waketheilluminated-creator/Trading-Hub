# Threat models (Trading Hub)

Short allow/deny tables for agents and reviewers. Prefer existing backend helpers over new client-side privileged fetches. This repo has no Supabase/Auth stack.

| Domain | Allow | Must deny | No side effects on deny | Test anchor |
| --- | --- | --- | --- | --- |
| BYOK / user-supplied API keys | User-provided OpenAI-compatible key used only for the requested `test`/`analyze` call via `studio/lib/ai/proxy.ts`. Persist the key in `sessionStorage` only when `rememberKey` is true. Redact keys in errors and provider copy (`studio/lib/ai/secrets.ts`). | Log, prompt, or response echo of keys; private / non-HTTPS / credential-in-URL endpoints; committing keys; treating a client “valid key” flag as entitlement. | No upstream fetch; no `sessionStorage` write of the key when `rememberKey` is false; error bodies stay redacted. | `studio/tests/ai-byok.test.mjs` |
| Backend market data / Context Packs | Server-assembled klines, markets, CVD, derivatives, L2 depth walls, history, and Deribit option open interest (`GET /api/options-oi`, BTC/ETH only) from public exchange APIs through `studio/app/api/*` and `enrichAnalyzeRequest`. Invalid venue/symbol/interval/currency/expiry → 400. Client-supplied books/walls/spot/OI are not entitlement. Geo-blocked venues → sanitized copy, no privilege escalation. | Treat client-supplied candles, order books, screenshots, or option books as historical series; screenshot / scroll-capture privilege; renderer SSRF to arbitrary hosts; leaking exchange legal-wall URLs unsanitized. | No privileged fetch; `media.screenshots` stays false; failed packs are `unavailable` without inventing values; `/api/depth` and `/api/options-oi` do not fetch on 400. | `studio/tests/ai-history.test.mjs`, `studio/tests/market-feed.test.mjs`, `studio/tests/market-depth.test.mjs`, `studio/tests/options-oi.test.mjs` |
| Auth / session | No first-party login exists. The only credential session is BYOK in `sessionStorage` (`studio/lib/ai/session.ts`). Chart drawing “session” is UI state only. | Inventing account/role/membership from client claims; using drawing session as auth; server trust of a client-set “remembered / authorized” flag without parsing rules. | No privilege grant. `parseByokSession` drops `apiKey` unless `rememberKey` is true. | `studio/tests/ai-byok.test.mjs` (BYOK session). **TODO:** dedicated deny tests if first-party auth is added. |
| Transpiler / studio (untrusted Pine) | Parse/transpile Pine to JS in-memory. Local CLI may write operator-specified output. `tools/pine-paster` may write only under `examples/` after filename sanitization. | Path traversal from user filenames; remote eval/exec of generated JS; exposing `src/reviewer.js` `executeImport` / `new Function` as a network service over untrusted Pine; `child_process` from renderer/client paths. | No write outside `examples/`; no host RCE; transpile failures return `success: false` without executing output. | `tools/pine-paster/app/api/save-example/route.js` (path check in code). `test/test.js` (transpile failures). **TODO:** dedicated path-traversal + “reviewer import not exposed remotely” tests. |
| Liquidation estimator spawn (manual refresh + auto-refresh) | `POST /api/liq-zones/refresh` (localhost + same-origin Origin) and the TH-BUG-06 server scheduler both call one refresher (`studio/lib/liq-refresh.ts`). It enforces: argv only from server env, no shell, a format-checked symbol, a server-chosen output path, single-flight, concurrency 2, a 30 s cooldown, a 90 s timeout, and validated swap-in. The scheduler symbols come from operator env (default BTC/ETH) plus overlay views over same-origin localhost GET (TTL 30 min, cap 6). | Cross-site or missing `Sec-Fetch-Site` GETs, probe GETs, and malformed symbols must not enrol a symbol. The scheduler must not run when the estimator is unconfigured or `LIQ_AUTO_REFRESH_SEC=0`, must not spawn directly, and must not overlap ticks. An unlisted symbol is dropped. | A denied request enrols nothing and spawns nothing. A failed run keeps the last good snapshot and backs off for one interval. | `studio/tests/liq-auto-refresh.test.mjs`, `studio/tests/liq-refresh.test.mjs` |
